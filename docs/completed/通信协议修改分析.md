## 一、需求明确

### 1.1 face_result 不需要两级确认

**原因**：
- face_result 是服务器主动推送的识别结果，不是用户发起的命令
- 开锁结果通过 log_report 上报即可
- 不需要 seq_id 和两级确认机制

**当前实现问题**：
- ✅ 代码中已实现了 esp32_ack（第一级确认）
- ✅ 代码中已实现了 ack（第二级确认）
- ❌ **但这是不必要的**，应该移除

### 1.2 query 命令需要两级确认

**原因**：
- query 是用户发起的命令，需要确认收到
- 需要等待 STM32 返回数据后才能发送最终 ack
- 支持超时处理（5秒）

**当前实现状态**：
- ✅ 代码中已实现了 esp32_ack（第一级确认）
- ✅ 代码中已实现了 PendingCommand 保存
- ✅ 代码中已实现了 UART 查询命令发送
- ✅ 代码中已在 HandleLockReportMessage() 中实现了 ack 发送
- ✅ **已完全实现，无需修改**

### 2.2 query 命令当前实现（application.cc 第 2350-2430 行）

```cpp
if (strcmp(type, "query") == 0) {
  auto seq_id = cJSON_GetObjectItem(root, "seq_id");
  auto msg_id = cJSON_GetObjectItem(root, "msg_id");
  auto command = cJSON_GetObjectItem(root, "command");
  std::string seq_id_str = cJSON_IsString(seq_id)   ? seq_id->valuestring
                           : cJSON_IsString(msg_id) ? msg_id->valuestring
                                                    : "";

  if (cJSON_IsString(command)) {
    std::string cmd_str = command->valuestring;
    ESP_LOGI(TAG, "查询命令: %s (seq_id=%s)", cmd_str.c_str(),
             seq_id_str.c_str());

    // ✅ 正确：立即发送 esp32_ack（第一级确认）
    if (!seq_id_str.empty()) {
      auto ws_protocol = dynamic_cast<WebsocketProtocol *>(protocol_.get());
      if (ws_protocol) {
        ws_protocol->SendEsp32Ack(seq_id_str, 0, "received");
      }
    }

    Schedule([this, cmd = cmd_str, seq_id_str]() {
      // ... 省略错误处理 ...

      // 确定 UART TYPE
      uint8_t uart_type = 0;
      if (cmd == "sensors") {
        uart_type = static_cast<uint8_t>(xiaozhi::CmdType::Q_SENSORS);
      } else if (cmd == "status") {
        uart_type = static_cast<uint8_t>(xiaozhi::CmdType::Q_STATUS);
      }

      if (uart_type != 0) {
        // ✅ 正确：保存待处理命令（type = QUERY）
        if (!seq_id_str.empty()) {
          PendingCommand pending_cmd;
          pending_cmd.seq_id = seq_id_str;
          pending_cmd.type = PendingCommandType::QUERY;
          pending_cmd.category = "query";
          pending_cmd.command = cmd;
          pending_cmd.uart_type = uart_type;
          pending_cmd.uart_subtype = 0;
          pending_cmd.timestamp_ms = esp_timer_get_time() / 1000;
          pending_cmd.esp32_ack_sent = true;
          pending_cmd.stm32_ack_received = false;
          pending_cmd.stm32_error_code = 0;
          pending_commands_[uart_type] = pending_cmd;
        }

        // ✅ 正确：发送查询命令到 STM32
        if (cmd == "sensors") {
          lock_control_->QuerySensors();
        } else if (cmd == "status") {
          lock_control_->QueryStatus();
        }
        // ✅ 正确：ack 将在收到 STM32 数据帧（RPT_ENV/RPT_STATE）后发送
      }
    });
  }
  return true;
}
```

**状态**：✅ 已完全实现，无需修改

### 2.3 query 命令的 ack 发送（HandleLockReportMessage 中）

在 `HandleLockReportMessage()` 函数中，已经实现了查询命令的 ack 发送：

```cpp
case RPT_ENV: {
  // ... 保存数据、上报服务器 ...
  
  // ✅ 正确：查询命令收到数据帧后发送 ack
  uint8_t query_type = static_cast<uint8_t>(xiaozhi::CmdType::Q_SENSORS);
  auto it = pending_commands_.find(query_type);
  if (it != pending_commands_.end()) {
    protocol_->SendAck(it->second.seq_id, 0, "OK");
    pending_commands_.erase(it);
  }
  break;
}

case RPT_STATE: {
  // ... 保存数据、上报服务器 ...
  
  // ✅ 正确：查询命令收到数据帧后发送 ack
  uint8_t query_type = static_cast<uint8_t>(xiaozhi::CmdType::Q_STATUS);
  auto it = pending_commands_.find(query_type);
  if (it != pending_commands_.end()) {
    protocol_->SendAck(it->second.seq_id, 0, "OK");
    pending_commands_.erase(it);
  }
  break;
}
```

**状态**：✅ 已完全实现，无需修改

## 七、总结

### 7.1 修改总结

| 项目 | 状态 | 说明 |
|------|------|------|
| face_result 两级确认 | ❌ 需要移除 | 不应该有 esp32_ack 和 ack |

### 7.2 关键要点

   - 不需要 seq_id
   - 不需要 esp32_ack
   - 不需要 ack
   - 开锁结果通过 log_report 上报

2. **query 是用户命令，需要确认**
   - 需要 seq_id
   - 需要 esp32_ack（立即）
   - 需要 ack（收到 STM32 数据后）
   - 已完全实现

3. **代码修改简单**
   - 只需修改 application.cc 中的 face_result 处理逻辑
   - 移除不必要的确认代码
   - 不影响其他功能
