# ESP32-S3 bread-compact-wifi-s3cam 平台引脚详解 (分组优化版)

本文档结合了 `bread-compact-wifi-s3cam` 平台的代码配置 (`config.h`) 和 ESP32-S3 的通用引脚功能，为该开发板的引脚使用情况提供一份完整、清晰的参考。文档首先按功能模块对**已使用**的引脚进行分组，最后统一列出**未使用**的引脚及其使用建议。

---

## (一) 已使用引脚功能分组

### 1. 摄像头 (Camera)

摄像头使用 8-bit DVP 并行接口和 I2C (SCCB) 控制接口，共占用 13 个引脚。

| GPIO   | 项目中使用功能          | 通用功能/特性         | 限制与建议               |
| :----- | :---------------------- | :-------------------- | :----------------------- |
| **11** | 摄像头 DVP 数据位 0     | `ADC2_CH1`, `TOUCH11` | DVP 并口数据线           |
| **9**  | 摄像头 DVP 数据位 1     | `ADC1_CH9`, `TOUCH9`  | DVP 并口数据线           |
| **8**  | 摄像头 DVP 数据位 2     | `ADC1_CH8`, `TOUCH8`  | DVP 并口数据线           |
| **10** | 摄像头 DVP 数据位 3     | `ADC2_CH0`, `TOUCH10` | DVP 并口数据线           |
| **12** | 摄像头 DVP 数据位 4     | `ADC2_CH2`, `TOUCH12` | DVP 并口数据线           |
| **18** | 摄像头 DVP 数据位 5     | `ADC2_CH8`            | DVP 并口数据线           |
| **17** | 摄像头 DVP 数据位 6     | `ADC2_CH7`            | DVP 并口数据线           |
| **16** | 摄像头 DVP 数据位 7     | `ADC2_CH6`, `U0RTS`   | DVP 并口数据线           |
| **13** | 摄像头像素时钟 (PCLK)   | `ADC2_CH3`, `TOUCH13` | DVP 时钟                 |
| **15** | 摄像头外部时钟 (XCLK)   | `ADC2_CH5`, `U0CTS`   | 为摄像头提供 20MHz 时钟  |
| **6**  | 摄像头垂直同步 (VSYNC)  | `ADC1_CH6`, `TOUCH6`  | DVP 同步信号             |
| **7**  | 摄像头水平参考 (HREF)   | `ADC1_CH7`, `TOUCH7`  | DVP 同步信号             |
| **5**  | 摄像头 SCCB 时钟 (SIOC) | `ADC1_CH5`, `TOUCH5`  | I2C 接口，用于控制摄像头 |
| **4**  | 摄像头 SCCB 数据 (SIOD) | `ADC1_CH4`, `TOUCH4`  | I2C 接口，用于控制摄像头 |

### 2. 显示屏 (Display)

显示屏使用 SPI 接口，共占用 6 个引脚。

| GPIO   | 项目中使用功能       | 通用功能/特性              | 限制与建议                                    |
| :----- | :------------------- | :------------------------- | :-------------------------------------------- |
| **19** | SPI 时钟 (CLK)       | `RTC_GPIO19`, **`USB_D-`** | **原生 USB, 已被复用**。原生 USB 功能不可用。 |
| **20** | SPI 数据 (MOSI)      | `RTC_GPIO20`, **`USB_D+`** | **原生 USB, 已被复用**。原生 USB 功能不可用。 |
| **45** | SPI 片选 (CS)        | -                          | **Strapping Pin**。                           |
| **47** | 数据/命令控制 (DC)   | -                          | 可用。                                        |
| **21** | 复位 (RST)           | `RTC_GPIO21`               | 可用。                                        |
| **38** | 背光控制 (Backlight) | `FSPIHD`                   | 可用 (JTAG)。                                 |

### 3. 音频 (Audio)

音频采用 Simplex I2S 模式，共占用 6 个引脚。

| GPIO   | 项目中使用功能  | 通用功能/特性        | 限制与建议    |
| :----- | :-------------- | :------------------- | :------------ |
| **1**  | I2S 麦克风 WS   | `ADC1_CH1`, `TOUCH1` | 可用。        |
| **2**  | I2S 麦克风 SCK  | `ADC1_CH2`, `TOUCH2` | 可用。        |
| **42** | I2S 麦克风 DIN  | `FSPIIO5`            | 可用 (JTAG)。 |
| **39** | I2S 扬声器 DOUT | `FSPIWP`             | 可用 (JTAG)。 |
| **40** | I2S 扬声器 BCLK | `FSPICS0`            | 可用 (JTAG)。 |
| **41** | I2S 扬声器 LRCK | `FSPIIO4`            | 可用 (JTAG)。 |

### 4. 板载元件与其他

| GPIO   | 项目中使用功能    | 通用功能/特性           | 限制与建议                                      |
| :----- | :---------------- | :---------------------- | :---------------------------------------------- |
| **0**  | **启动/功能按钮** | `ADC1_CH0`, `RTC_GPIO0` | **Strapping Pin**。需确保正常启动时不会被拉低。 |
| **48** | **板载 LED**      | -                       | 可用。                                          |
| **14** | **测试用灯**      | `ADC2_CH4`, `TOUCH14`   | 可用作通用 GPIO。                               |

## (二) 未使用引脚列表

### 1. 未使用且可安全使用的引脚

这些引脚在项目中未被分配，且没有严重的使用限制，可用于功能扩展。

| GPIO   | 通用功能/特性 | 限制与建议                                                  |
| :----- | :------------ | :---------------------------------------------------------- |
| **43** | `U0TXD`       | **默认串口 TX**。可复用为通用 GPIO，但会失去日志功能。      |
| **44** | `U0RXD`       | **默认串口 RX**。可复用为通用 GPIO，但会失去烧录/日志功能。 |

### 2. 未使用但受限或不建议使用的引脚

这些引脚要么是重要的 Strapping Pin，要么内部已连接到 Flash/PSRAM，**强烈不推荐**用于自定义功能。

| GPIO         | 通用功能/特性        | 限制与建议                                                           |
| :----------- | :------------------- | :------------------------------------------------------------------- |
| **3**        | `ADC1_CH3`, `TOUCH3` | **Strapping Pin**。与 JTAG 和 efuse 相关，强烈建议不使用。           |
| **35 36 37** | -                    | **不建议使用** (内部连接到 PSRAM)。                                  |
| **46**       | -                    | **Strapping Pin**。**强烈建议不用**，芯片启动模式/ROM 代码日志打印。 |
