# 语音资源开发指南

**最后更新**: 2025-12-10

---

## 概述

本指南介绍如何为智能猫眼门锁系统添加和管理语音资源。

---

## 语音资源类型

### 1. TTS 语音反馈

用于人脸识别结果反馈：

- "欢迎回家"
- "识别失败，请重试"
- "陌生人，请按门铃"

### 2. 系统提示音

用于系统状态提示：

- 开机提示音
- WiFi 连接成功提示音
- 错误提示音

---

## 添加语音资源

### 1. 准备音频文件

- 格式：WAV 或 MP3
- 采样率：16000 Hz
- 声道：单声道
- 位深度：16 bit

### 2. 转换为 C 数组

使用工具将音频文件转换为 C 数组：

```bash
xxd -i audio.wav > audio.h
```

### 3. 添加到项目

将生成的头文件添加到 `main/assets/` 目录。

---

## 播放语音

```cpp
// 播放语音资源
audio_service->PlayAudio(audio_data, audio_size);
```
