# ESP32S3功能实现清单
根据需求文档，ESP32S3作为系统中的高级处理单元，主要负责数据采集和上传，重要功能均由服务器实现，具体功能实现如下：

## 1. 物联网连接模块
- 实现WiFi/4G双模联网功能
- 云端数据同步与管理，支持被服务器远程控制
- 设备OTA远程升级支持

## 2. AI视觉处理系统
- 广角摄像头(120°视场角)图像采集与处理
- 人脸识别算法实现（服务器端实现，提供mcp接口调用）
- 异常行为识别(逗留、窥探、肢体冲突、暴力破坏)（服务器端实现，尚未确定通过AI还是参数检测实现）
- 视频流实时传输与压缩处理（供用户远程查看监控）

## 3. 语音交互系统
- NLP自然语言处理引擎（调用AI）
- 情境化自动应答逻辑（区分不同说话人采取不同逻辑，通过给不同的人预设不同的提示词实现）
- 本地语音唤醒功能
- 自动语音引导(快递/外卖放置指引)（服务器端实现，本地仅需回复音频，并上传实时画面即可）
- 语音指令识别与执行(门锁状态、电量查询等)（通过mcp实现，即查看设备状态信息）

## 4. 高级应用逻辑
- 访客智能识别与分类处理（通过人脸或语音区分）
- 家庭关怀场景逻辑(老人监护、儿童守护)（服务器端实现，本地仅需播放服务器传输的音频即可）
- 情感化交互(个性化欢迎语、亲情提醒)（服务器端实现，本地仅需播放服务器传输的音频即可）
- 智能家居联动(与灯光、空调等设备协同)（通过HA的mcp实现）
- 72小时循环云存储管理（部分监控需要保存）
- 远程视频通话功能（上传音视频流，接收音频流）

## 5. 用户界面与体验
- 室内大屏显示监控画面和电量等信息（通过mcp控制，用户可通过指令开启）
- 访客记录分类与摘要生成（由服务器整理相关数据）

## 6. 系统协同
- 实现与STM32F103C8T6的通信协议（串口通信）
- 由Stm32控制外设：门锁模块、密码模块、指纹模块、nfc模块、补光灯模块、人体红外模块（用于检测门前是否有人）、陀螺仪模块（用于检测门锁是否被暴力破坏）

## 7. 低功耗管理
- 默认运行在低功耗状态，可被stm32、服务器和语音唤醒词唤醒。
