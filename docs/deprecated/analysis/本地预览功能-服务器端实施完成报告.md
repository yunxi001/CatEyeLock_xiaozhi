## 3. 技术实现

### 3.1 插件系统实现

#### 3.1.1 Function Schema 定义

```python
CONTROL_LOCAL_PREVIEW_DESC = {
    "type": "function",
    "function": {
        "name": "control_local_preview",
        "description": (
            "控制本地预览功能的开启或关闭。本地预览功能允许在 ESP32 的 LCD 屏幕上实时查看摄像头画面。"
            "当用户说以下内容时调用此函数："
            "启动本地预览：'显示监控画面'、'打开监控画面'、'让我看看门口'、'打开本地预览'、'屏幕显示摄像头'、'打开屏幕'、'显示摄像头'；"
            "停止本地预览：'关闭监控画面'、'隐藏监控画面'、'关闭本地预览'、'关闭屏幕显示'、'关闭屏幕'、'隐藏摄像头'"
        ),
        "parameters": {
            "type": "object",
            "properties": {
                "action": {
                    "type": "string",
                    "enum": ["start", "stop"],
                    "description": "操作类型：start 表示启动本地预览，stop 表示停止本地预览"
                }
            },
            "required": ["action"]
        }
    }
}
```

**关键点**：

- 在 `description` 中提供了丰富的触发词示例
- LLM 会根据这些示例自动泛化到相似表达
- 无需硬编码触发词匹配规则

- 轮询方式等待 ESP32 响应（避免阻塞）
- 完整的错误处理和日志记录

### 3.2 响应处理机制

#### 3.2.1 响应缓存

```python
# 在插件中等待响应
async def _wait_for_response(conn, timeout: float = 10.0):
    """轮询检查连接对象的响应缓存"""
    while True:
        if conn._local_preview_response is not None:
            response = conn._local_preview_response
            conn._local_preview_response = None  # 清除缓存
            return response

        if elapsed >= timeout:
            return None

        await asyncio.sleep(0.1)
```

#### 3.2.2 响应处理器

```python
class LocalPreviewHandler(TextMessageHandler):
    """处理 ESP32 返回的 local_preview 响应"""

    async def handle(self, conn, msg_json: dict):
        # 将响应存储到连接对象的缓存中
        conn._local_preview_response = msg_json
```

**工作流程**：

1. ESP32 发送响应 → `LocalPreviewHandler` 接收
2. 响应存储到 `conn._local_preview_response`
3. 插件函数轮询检查缓存
4. 获取响应后清除缓存

## 8. 已知问题和限制

### 8.1 当前限制

1. **响应等待机制**
   - 使用轮询方式，可能有轻微延迟（100ms 间隔）
   - 未来可优化为事件驱动机制

2. **并发请求**
   - 当前实现不支持同一设备的并发请求
   - 后续请求会覆盖前一个请求的响应缓存

3. **状态管理**
   - 未实现设备状态持久化
   - 服务器重启后状态丢失

### 8.2 后续优化方向

1. **Phase 2 功能**
   - 实现设备状态管理（Redis/MySQL）
   - 添加互斥检查（服务器端预检查）
   - 提供 HTTP API 接口（APP 端控制）

2. **性能优化**
   - 使用事件驱动替代轮询
   - 支持并发请求队列
   - 添加响应缓存过期机制

3. **功能增强**
   - 支持本地预览参数配置（分辨率、帧率）
   - 添加使用统计和监控
   - 提供状态查询接口
